# image_generation

`mcp.image_generation` — image generation, edit, and review.

## Purpose

Generate and edit images using an upstream image model (configurable).

## Tools

- `image_generate` — produce a new image from a prompt
- `image_edit` — edit an existing image
- `image_review` — request a review pass on a generated image

## Configuration

Set `IMAGE_API_KEY` (and provider-specific variables) before starting alfred.
